# Calculadora de Incremento Salarial UGT (2025-2028)

Simulador de retribuciones para empleados públicos y personal sanitario basado en el **Acuerdo Marco para la Mejora del Empleo Público y el Servicio a la Ciudadanía (2025-2028)** pactado por **UGT** con el Gobierno de España, y los Reales Decretos-leyes correspondientes (RDL 14/2025 y actualización retributiva 2027).

## Senda de Incrementos Salariales
- **2025:** Subida del **2,5%** consolidable (2% fijo + 0,5% IPC/consolidado).
- **2026:** Subida fija del **1,5%** + cláusula de garantía IPC del **0,5%** adicional retroactiva.
- **2027:** Subida fija del **4,5%** aprobada por Real Decreto-ley (+0,5% de regularización IPC de 2026 abonado en el 1T de 2027, alcanzando un alza efectiva del **5,0%**).
- **2028:** Subida fija del **2,0%** para cerrar el ciclo plurianual del acuerdo.
- **Acumulado global:** Incremento directo del **~11,0%** y superior al **11,4%** compuesto.

## Características
- **Base de cálculo 2025:** Configuración del salario mensual bruto de 2025 (incluyendo selección de 12 o 14 pagas).
- **Selector de año objetivo:** Simulación directa de la nómina para 2026, 2027 o 2028.
- **Cálculo de retroactividad y atrasos:** Estimación de atrasos para 2026 (consolidación 2025) y para 2027 (cláusula de inflación 2026 abonada en 1T 2027).
- **Garantía IPC:** Control para activar o verificar el impacto de la cláusula ligada al IPC.
- **Visualización interactiva:** Cronología completa de la evolución retributiva año a año (2024-2028).
- **Responsive:** Interfaz moderna y adaptable con Tailwind CSS.

## Tecnologías
- React 19
- Tailwind CSS
- Lucide React (Iconos)
- Recharts (Gráficos)
- TypeScript
